# Fix Issues After Merge to Main

## Context
Merged `feature/production-readiness` (38 commits) into `main`. Found 7 issues requiring fixes before the project can build and be production-ready.

## Issues & Fixes

### 1. [CRITICAL] Firebase misconfiguration — breaks build
**Files:** `app/build.gradle`, `build.gradle`

**Problem:** `com.google.firebase.crashlytics` plugin and Firebase deps (BOM, Crashlytics, Analytics, Performance) are declared, but:
- `google-services.json` is missing from `app/`
- `com.google.gms.google-services` plugin is not applied in `app/build.gradle`

**Fix:**
1. In `app/build.gradle`, add at the very end:
   ```gradle
   apply plugin: 'com.google.gms.google-services'
   ```
2. Add `google-services.json` to `app/` from Firebase console (see `docs/FIREBASE_SETUP.md`).

**Validation:** Run `./gradlew :app:compileDebugKotlin` — must not fail with "google-services.json not found".

---

### 2. [HIGH] Missing `keystore.properties` — breaks release build
**File:** `app/build.gradle`

**Problem:** Release signing config reads `keystore.properties`, but only `keystore.properties.example` exists.

**Fix:**
1. Copy `keystore.properties.example` → `keystore.properties`
2. Fill in real values (or set env vars `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).

**Validation:** `./gradlew :app:assembleRelease` succeeds (or signing config is recognized).

---

### 3. [MEDIUM] `.gradle/` committed, no `.gitignore`
**Problem:** `.gradle/wrapper/dists/` (129 MB of Gradle binaries) is tracked in git.

**Fix:**
1. Create `.gitignore`:
   ```
   .gradle/
   build/
   local.properties
   *.iml
   .idea/
   *.keystore
   captures/
   ```
2. Remove from index without deleting files:
   ```bash
   git rm -r --cached .gradle
   git add .gitignore
   git commit -m "chore: add .gitignore and stop tracking .gradle"
   ```

**Validation:** `git ls-files .gradle` returns empty.

---

### 4. [MEDIUM] Non-standard SQLCipher `openHelperFactory`
**File:** `app/src/main/java/com/phoneguard/data/local/AppDatabase.kt:204-212`

**Problem:** `SupportFactory` is used with manual `SupportSQLiteOpenHelper.Configuration.builder`, which is unnecessarily complex and may cause issues.

**Fix:** Replace the custom block with the standard SQLCipher pattern:
```kotlin
.openHelperFactory { config ->
    SupportFactory(databaseKeyManager.getDatabasePassphrase()).create(config)
}
```

**Validation:** App launches, DB opens without crash.

---

### 5. [LOW] Duplicate permissions in `AndroidManifest.xml`
**File:** `app/src/main/AndroidManifest.xml`

**Problem:** `FOREGROUND_SERVICE` and `FOREGROUND_SERVICE_LOCATION` declared twice (lines 11/88 and 13/92). Also `FOREGROUND_SERVICE_MICROPHONE` is declared (line 14) but `ShoulderSurferService` uses `foregroundServiceType="camera"`, not microphone.

**Fix:**
1. Remove duplicate `FOREGROUND_SERVICE` and `FOREGROUND_SERVICE_LOCATION` declarations (keep only the first occurrences).
2. If microphone FGS is needed for future audio recording, keep it; otherwise remove line 14.

**Validation:** `./gradlew :app:mergeDebugResources` succeeds.

---

### 6. [LOW] `exported="false"` on broadcast receivers
**File:** `app/src/main/AndroidManifest.xml:200,210`

**Problem:** `SimSwapReceiver` and `PackageAddedReceiver` have `exported="false"`. On Android 10–11, `BOOT_COMPLETED` and `PACKAGE_ADDED` may require `exported="true"` to receive broadcasts.

**Fix:**
1. Set `android:exported="true"` on both receivers.
2. For `SimSwapReceiver`, optionally add `android:permission="android.permission.BROADCAST_STICKY"` if needed.

**Validation:** Test on API 29–30 emulator: SIM swap detection and new-package notification still work.

---

### 7. [INFO] Database version jumped 3 → 7
**File:** `app/src/main/java/com/phoneguard/data/local/AppDatabase.kt:38`

**Problem:** Room DB version went from 3 to 7 with 4 new migrations. Existing users will apply all migrations sequentially.

**Action:** Verify each migration is correct:

- `MIGRATION_5_6`: Adds `category` column to `vault_items` with backfill — safe
- `MIGRATION_6_7`: Adds `trafficDirection` column to `firewall_logs` — safe

**Validation:** Run migration tests: `./gradlew :app:testDebugUnitTest --tests "*Migration*"` (after adding test if missing).
