# Ручное тестирование

Сценарии, которые нельзя закрыть юнит-тестами: реальные разрешения, службы, системные диалоги и OEM-прошивки.
Минимальный набор устройств: API 26 (Android 8), 29, 31, 33, 34, 35 — плюс хотя бы один Samsung/Xiaomi/Huawei
(у них агрессивное убийство фоновых служб).

## 1. Онбординг и разрешения

- [ ] На первом запуске показывается онбординг, после него — дашборд.
- [ ] Камера, SMS, телефон, геолокация, уведомления запрашиваются с пояснением, зачем.
- [ ] Отказ в разрешении не роняет приложение: соответствующий экран показывает «нет доступа» и как его выдать.
- [ ] На Android 13+ без `POST_NOTIFICATIONS` блокировки работают, но без уведомлений.

## 2. Блокировка звонков

- [ ] Номер из чёрного списка не звонит (журнал: запись `isSms = false`).
- [ ] Номер из белого списка проходит, даже если он же есть в спам-базе.
- [ ] Номер в другом формате (`0170…` и `+49 170…`) матчится — проверка нормализации.
- [ ] Скрытый номер блокируется при включённом «блокировать скрытые».
- [ ] Уведомление о блокировке приходит, номер в нём замаскирован.
- [ ] CSV-импорт добавляет номера и не пускает мусор.

## 3. Фильтр SMS

- [ ] SMS с номера из чёрного списка: запись в журнале, уведомление «SMS заблокировано».
- [ ] Номер из белого списка проходит, даже если он есть в спам-базе.
- [ ] Длинное (многочастное) SMS от одного отправителя даёт **одну** запись в журнале.
- [ ] Текст «ссылка + давящие слова» от неизвестного номера даёт «Подозрительное SMS».
- [ ] Если PhoneGuard **не** приложение SMS по умолчанию, сообщение всё равно приходит в системное
      приложение, а PhoneGuard только предупреждает (это ожидаемое поведение, а не баг).
- [ ] Если PhoneGuard назначено приложением SMS по умолчанию, блокировка по номеру отменяет доставку.
- [ ] Анти-воровские команды (`LOCK`, `WIPE`, …) продолжают работать — фильтр не перехватывает их раньше.

## 4. Брандмауэр (VPN)

- [ ] Включение VPN показывает постоянное уведомление, выключение — убирает его.
- [ ] Приложение с правилом «блокировать всё» теряет сеть, остальные приложения работают.
- [ ] Правило «только Wi-Fi» переключается при переходе на мобильную сеть (туннель пересоздаётся).
- [ ] IPv6-трафик заблокированного приложения тоже не проходит.
- [ ] Журнал блокировок пополняется, но не чаще ~10 записей в секунду.
- [ ] После отзыва VPN-разрешения в системных настройках сервис корректно останавливается.

## 5. Полное сканирование

- [ ] Проходят все 16 шагов, прогресс переводится и не «зависает» на последнем шаге.
- [ ] Повторный запуск во время скана не запускает второй (шаг `ALREADY_RUNNING`).
- [ ] Отмена скана не оставляет включённый индикатор.
- [ ] Отчёт сохраняется в историю, сравнение с предыдущим показывает разницу.
- [ ] PDF-экспорт создаёт файл, которым можно поделиться.
- [ ] На устройстве без root все проверки дают осмысленные результаты (нет ложных «критично»).

## 6. Чек всего телефона

- [ ] Экран открывается с дашборда и из настроек.
- [ ] Оценка 0..100 соответствует состоянию устройства (блокировка экрана, шифрование, патч, ADB).
- [ ] Результат сохраняется: после перезапуска дашборд показывает его без нового аудита.
- [ ] На устройствах с ограниченным профилем аудит не падает.

## 7. Сейф

- [ ] Разблокировка по биометрии и по PIN.
- [ ] Импорт изображения/видео/документа, лимит 50 МБ срабатывает.
- [ ] Предпросмотр открывает файл во внешнем приложении, копия остаётся в кеше и удаляется при следующем предпросмотре.
- [ ] `FLAG_SECURE`: скриншот и запись экрана блокируются.
- [ ] Удаление файла требует подтверждения.

## 8. Анти-вор

- [ ] PIN задаётся и проверяется, после N неудач — блокировка.
- [ ] Замена SIM обнаруживается (`SimSwapReceiver`). При закрытом приложении приходит
      уведомление «Вы поменяли SIM?» (канал «Смена SIM-карты», id 4101), тап по нему открывает
      экран подтверждения — в том числе поверх блокировки экрана.
- [ ] «Да» — событие помечается подтверждённым, уведомление исчезает, устройство не блокируется.
- [ ] «Нет» — включается lost mode, координаты уходят доверенным контактам, устройство блокируется
      (при активном Device Admin).
- [ ] Тревога по SMS играет и останавливается кнопкой (в том числе из уведомления).
- [ ] Координаты уходят на доверенный номер; без разрешения `SEND_SMS` — ничего не отправляется.
- [ ] Команды `WIPE`/`LOCK` работают только там, где это разрешено (device owner / device admin),
      в остальных случаях пользователь видит понятное сообщение.
- [ ] Детектор подглядывания запускается с разрешением камеры и не падает без него.

## 9. Настройки и приватность

- [ ] Переключение языка применяется сразу и сохраняется после перезапуска.
- [ ] Тёмная тема следует системе и ручному переключателю.
- [ ] Экспорт логов создаёт JSON.
- [ ] Удаление данных очищает базу, файлы сейфа и crash-отчёты.
- [ ] Threat intelligence выключен по умолчанию; при включении уходит только имя хоста
      (проверяется через прокси).

## 10. Ярлыки и ссылки

- [ ] Долгое нажатие на иконку: ярлыки «Антивор», «Блокировщик», «Брандмауэр», «Сейф» открывают
      соответствующие экраны, а не дашборд.
- [ ] `adb shell am start -a android.intent.action.VIEW -d "phoneguard://settings"` открывает настройки;
      то же для `phonecheck`, `fullscan`, `vault`.
- [ ] Ссылка, открытая при уже запущенном приложении, не создаёт вторую Activity (`singleTop`).

## 11. Фон и обслуживание

- [ ] `ScheduledFullScanWorker` срабатывает по расписанию (и только при включённой настройке).
- [ ] `DataCleanupWorker` удаляет старые записи согласно retention.
- [ ] Уведомление о battery optimization показывается и ведёт в системные настройки.
- [ ] На Xiaomi/Huawei службы не убиваются после добавления в исключения.

## Замечания

- VPN и foreground-службы не должны держать устройство в состоянии бодрствования: проверяйте `batterystats`.
- Любое расхождение с этим списком — повод завести issue с моделью, версией Android и логом
  (`adb logcat -s PGVpn:V PhoneGuardEvents:V SmsSpamReceiver:V`).
