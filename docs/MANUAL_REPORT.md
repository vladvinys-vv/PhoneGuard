# Отчёт ручного прогона

Заготовка под `docs/MANUAL_TESTING.md`. Заполняется по результатам прогона
`python3 tools/manual_check.py --device <серийный номер> --logcat /tmp/pg.log --neighbour
--report /tmp/manual-report.md`: скрипт делает механическую часть и пишет ту же таблицу, что ниже.
Руками остаются только сценарии, требующие интерфейса (13.3 и 13.5) и второго телефона (13.2).
