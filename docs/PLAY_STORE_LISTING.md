# PhoneGuard — Play Store Listing

## Short Description (80 characters)
Защита от взлома, блокировщик звонков и брандмауэр.

## Full Description
PhoneGuard — это многофункциональный защитник для Android, который объединяет антикражную защиту, блокировку нежелательных звонков и SMS, защищённое хранилище, сканер конфиденциальности и VPN-брандмауэр в одном приложении.

### Основные функции
- **Антивор**: PIN-код, обнаружение смены SIM, удалённая блокировка и стирание, фото при неудачных попытках, защита от подглядывания.
- **Блокировщик звонков & SMS**: чёрный/белый список, база спама, импорт CSV, умные правила блокировки.
- **Брандмауэр**: контроль трафика по приложениям, блокировка Wi-Fi/мобильных данных, логи блокировок, статистика.
- **Полное сканирование**: 13 проверок безопасности, история сканов, сравнение результатов, экспорт PDF-отчётов.
- **Защищённое хранилище**: шифрование фото, видео и документов, биометрическая аутентификация, защита от скриншотов.
- **Сканер конфиденциальности**: анализ разрешений приложений, обнаружение избыточных доступов.
- **Проверка на шпионское ПО**: поиск скрытых приложений, сервисов доступности и администраторов.
- **SIM-swap защита**: уведомления о смене SIM, автоответ на резервный номер.

### Безопасность
- SQLCipher-шифрование базы данных + Android Keystore.
- SSL pinning для внешних соединений.
- Логирование всех событий с возможностью экспорта.
- Open-source friendly архитектура (DI, clean layers).

### Требования
- Android 8.0 (API 26) и выше.
- Разрешения: камера, SMS, телефон, местоположение (по необходимости).
- Для брандмауэра требуется VPN-разрешение.
